## 先下载素材（必须）

动画素材（86 个动作，约 310 MB）**不在仓库内**，请先下载并解压：

1. 打开 [Releases](https://github.com/zhongyi0102/dafeiyu-pet/releases/latest)
2. 下载 `dafeiyu-sprites.zip`
3. 解压到项目根目录，确认存在 `sprites/anim/idle_breath/0001.png` 这样的路径

```text
dafeiyu-pet/
├── 桌宠.py
├── sprites/
│   ├── icon.png
│   └── anim/          ← 解压到这里
│       ├── idle_breath/
│       └── ...（86 个动作）
└── tools/
```

> 没放素材也能启动，但宠物会显示成占位图、动作不可用。

## 快速开始

需要 **Python 3.11+**

```bash
pip install -r requirements.txt
# 或只装界面依赖
pip install PySide6
```

双击 `启动桌宠.bat`（会自动优先使用 `.venv`），或：

```bash
python 桌宠.py
```

> 首次运行会自动生成 `config.json` / `chats.json` / `memory.json`。
> 想用 AI 聊天和余额查询，先右键 →「设置 Key」填入 DeepSeek API Key（存在本地 `config.json`）。

## 功能

### 三视图与模式

- 左右走用**侧面**（自动镜像）、向上走用**背面**、向下走用**正面**；转向时 150ms 交叉淡入，不闪白。
- 三种模式：**自由散步 / 跟随鼠标 / 原地待着**。
  - 「原地待着」只显示**正面**，不会出现侧面/背面，也不会自己乱走。

### 帧序列动画（可选）

给动作加图片帧序列（不加就用原来的代码变形，两者自动切换）：

1. 建目录 `sprites/anim/<动作名>/`，放 `0001.png`、`0002.png` …（**所有帧同一画布尺寸**，按文件名排序播放）
2. 在 `桌宠.py` 的 `ACTIONS` 里登记动作（想精细控制才需要）：

```python
"dance": {
    "category": "idle", "weight": 5, "duration": 2.4, "moves": False,
    "frames_dir": "dance",   # 默认 = 动作名，可省略
    "fps": 12.0,             # 帧率（默认 12）
    "loop": True,            # 循环（默认 True）
    "hold_last": True,       # 非循环时停在最后一帧
    "facing": "front",       # front / side / back，朝向不匹配时回退三视图
},
```

- 所有帧以**脚底线**为基准绘制，镜像时脚底不动；和三视图 / 拖拽 / 甩抛 / 点击回应 / 气泡完全兼容。
- 缺帧、目录为空、尺寸不一致 → 记 `error.log` 并自动回退代码变形，不崩溃。
- 首次播放预加载 + 按宠物大小预缩放，LRU 缓存上限 6 个动作（`frame_anim.max_cache` 可改 1~64）。
- 播放被打断（拖拽 / 甩抛 / 点击）立即停止回到正常显示。
- 右键 →「动作」里有帧的动作标 **【帧】**，方便逐个调试；菜单底部显示「帧动作：N / 总数」和「释放帧缓存并重扫」。
- 设置 →「动画」有**帧序列动画总开关**（默认开）、已加载动作数、估算内存（MB）。

### 视频转帧动画工具

`tools/make_frames.py`：把 AI 生成的绿幕视频（即梦 / 可灵 / Runway 等输出的 mp4）
一键转成 `sprites/anim/<动作名>/0001.png ...`：

```
.venv\Scripts\python.exe -m pip install Pillow numpy        # 首次
.venv\Scripts\python.exe tools\make_frames.py dance.mp4 dance
```

- ffmpeg 抽帧（`--fps`，默认 15）、chromakey 抠纯绿背景（`--key-color` / `--similarity` / `--blend` 可调），
  非纯色背景可用 `--rembg` 逐帧 AI 抠图（需另装 rembg）。
- 自动去绿边（despill）、边缘羽化、预乘 alpha，避免缩放时边缘发黑/发绿。
- 自动裁剪到所有帧不透明区域的并集并统一尺寸，**脚底线对齐**（与桌宠绘制基准一致）。
- `--loop-fix` 首尾淡接：首尾差异大时自动裁掉尾部若干帧，让循环更自然。
- 输出白底 / 黑底两张预览 GIF 到 `tools/preview/`，分别检查边缘和暗边。
- ffmpeg 不在 PATH 时给出三种安装方式的明确提示（或用 `--ffmpeg` 指定路径）；`--check` 只查依赖。

完整参数见 项目说明.md 第 12.6 节。

### 待机与转向（第 9 批）

- **转向是 340ms 的转身过程**：压扁到最窄（16%）并停留一下 → 在最暗、最窄时切换朝向图（配合暗色遮罩和宽度补偿，几乎看不出换图）→ 展开回弹 + 小跳；脚底线全程不动；30% 概率冒一句「嗯？」「哼」。
- **待机动作分三层**：小动作（70%，无冷却）/ 中动作（25%，同动作冷却 30 秒）/ 大动作（5%，冷却 3 分钟）；
  各层概率可在设置 →「动画」里调。
- **久没理它会犯困**：5 分钟后打哈欠揉眼睛变多，10 分钟后想坐下，20 分钟后直接睡着（Zzz 气泡），
  随便摸一下就醒。
- **时段感知**：夜里的动作带 `time_of_day: night` 会出现得更频繁（只加权不强制）。
- **连招**：偶发「打哈欠 → 揉眼睛 → 伸懒腰」整段播放，被拖拽或点击就中断。
- **代码动作幅度**：呼吸起伏 4.4%、摇摆 8.5°、伸懒腰 +6%（纵向幅度刻意收敛，避免"突然长高"；横向/旋转更明显）；默认"强"档，可调弱/中。
- 有帧动画的动作优先播帧，代码变形版本权重降到 40%。
- 设置 →「动画」：转向强度、代码动作强度、三层概率滑块，以及**调试面板**
  （当前待机状态、最近 20 个动作、帧动作数与内存）。

### 动作素材（画师原画）

待机、移动、节日动作**全部使用画师原画帧序列**（来自 [dsh-pet](https://github.com/PC2005-cloud/dsh-pet)，
106 段 webm），不再是代码硬凑的缩放旋转——这是观感自然的关键。

- **31 个动作**：待机 18 + 移动 2 + 节日 7 + 转向 4（转向是功能性代码实现）。
- 每个动作都用 `tools/anim_audit.py` 客观审计过（闭合度 / 节奏方差 / 跳帧 / 脚底漂移），
  **差的已删除**，保留的全部达标。
- **播放速度与原视频一致**：12fps × 120 帧 = 10 秒（`tools/convert_all.py` 统一处理）。
- `tools/make_frames.py` 支持 **webm VP9 alpha 直读**，无需绿幕抠图；
  `--every` / `--max-frames` 控制帧数与体积。
- `tools/convert_all.py` 一键批量转换全部素材（含 PNG 量化压缩）。
- 节日动作（写福字 / 舞狮头 / 赏月 / 讨糖南瓜灯 / 堆雪人 / 赏菊 / 放河灯）
  由时节特效触发，不进随机链。

### 更多动画联动

借鉴 [dsh-pet](https://github.com/PC2005-cloud/dsh-pet) 的设计：

- **余额 6 档专用动作**：钱袋满溢 → 金袋叮当 → 钱袋如常 → 数金皱眉 → 袋空如洗 → 分文不剩。
- **工作状态联动**：AI 思考时播「思考冒泡」、输出时「忙碌点按」、完成「雀跃庆祝」、出错「垂头叹气」，
  打开聊天窗口时「原地踱步」等你说话。
- **喂食动画**：喂 🐟 吃大闸蟹、🍰 吃冰淇淋、🍭 吃糖葫芦、🍡 吃汤圆、💎 **吃 Token**。
- **时段 9 档**（凌晨/清晨/早上/上午/中午/下午/傍晚/晚上/深夜）+
  **节日三段窗口**（提前预热 / 假期中 / 过后回味）。
- **待机池 50 个动作**：撸猫、荡秋千、骑木马、踢毽子、放风筝、吹气球、抽陀螺、拆礼物、
  变鸽子、扑克魔术、三球抛接、下五子棋、动物环绕、凭空生花、女仆舞…

### 动画链


- 每个动作在 `ACTIONS` 里登记：`category`（idle / turn / move）、`weight`、`duration`、`moves`。
- 动作播完按「类别权重 × 动作权重」随机选下一个，**不会连续重复**同一动作。
- 类别权重默认 待机 10 / 转向 5 / 移动 5，可在 `config.json` 的 `animation_weights` 调整。
- **新增动作只要在 `ACTIONS` 登记一行**，右键「动作」菜单会自动出现（中文名在 `ACTION_LABELS`，缺失时显示英文 key）。

### 拖拽与甩抛（`physics.py`）

- 拖拽用**阻尼弹簧**追随鼠标（刚度 `spring_stiffness`、阻尼 `spring_damping` 可调），不是硬贴。
- 松手按最近 100ms 的平均速度抛出，速度太小则原地放下。
- 重力 / 弹性 / 摩擦 / 总力度 / 顶部反弹 / 互撞开关都在 `config.json` 的 `physics` 字段。
- 物理逻辑是**独立的纯 Python 模块**（`physics.py`，不依赖 Qt），可直接单元测试。
- 多屏：边界按宠物**当前所在显示器**的 `availableGeometry` 计算（自动扣任务栏），可跨屏抛掷；屏幕之间有空洞时自动落到最近的屏。
- **宠物互撞**：多开时碰到会互相弹开（默认关闭）。
- 接食物小游戏自动覆盖**宠物所在的那块屏幕**。

### AI 聊天（多会话 · 左右两栏）

```
┌────────────┬──────────────────────────────┐
│ ＋ 新对话 ‹│  消息区（空白时显示头像+欢迎语）│
│            │                              │
│ 会话列表   │                              │
│ (倒序/高亮)│                              │
│            ├──────────────────────────────┤
│ 记忆  设置 │  输入框（2~6 行自适应）      │
│            │  用量小字          发送/停止 │
└────────────┴──────────────────────────────┘
```

- **左栏（180px，可收起）**：顶部「＋ 新对话」（主按钮），中间会话列表（按最近更新倒序、当前项高亮），
  底部「记忆」「设置」两个次要按钮。会话项**右键可重命名 / 删除**。
  点「‹」收起成 34px 窄条，点「›」展开；状态会记住。
- **空会话**：当前会话没消息时点「＋ 新对话」不重复新建；多余的空会话会自动清理（只留最近一个）。
- **设置菜单**：Key 项显示「已设置 / 未设置」；「删除当前对话」为红字，与清空之间有分隔线。
- **右栏**：上方消息区，下方输入区。
- **输入框**：默认约 2 行，随内容自动增高，**最多 6 行**；右下角「发送」在生成中变「停止」。
- **用量小字**：输入框下方左侧 `输入 X · 输出 Y · 缓存命中 Z%`，灰字小号，
  窗口变窄时省略号截断（不会挤掉发送按钮）；悬停显示累计用量。
- **清空 / 删除**只在「设置」下拉里，都保留二次确认，生成中禁用。
- **空白状态**：没有消息时消息区居中显示宠物头像（约 120px 高）+ 欢迎语，有消息后自动消失。
- **样式**：淡蓝色系统一（强调色、左栏底色都在文件顶部 `CHAT_THEME_LIGHT/DARK` 常量里），
  跟随系统深/浅色；窗口最小宽度 560。
- **流式输出**（`stream=true`），请求在后台线程，界面不卡；可中途停止并保留已收到内容。
- **人设可编辑**：默认人设是傲娇鲸鱼娘（称呼主人/笨蛋主人，嘴上嫌弃心里在意，不骂人）。
  设置 →「聊天」页可直接改人设并保存（存 `config.json` 的 `persona`），带「恢复默认」。
- **回复长度可控**：简短（80 字，默认）/ 正常（200 字）/ 详细（不限），
  另有 `max_tokens` 上限（默认 400，可调 200~2000）。同一人设+风格下不破坏前缀缓存。
- 新会话发第一条消息后自动用前 15 字命名（手动改过名的不再覆盖）。
- 历史存 `chats.json`，重启自动加载；长会话只先渲染最近 50 条，顶部「加载更早消息」。
- **前缀缓存友好**：开头永远是同一段 `system`（人设 + 长期记忆），历史只追加不重排；接近上下文上限才把较早内容总结成「前情摘要」。
- 窗口大小与左栏收起状态都记在 `config.json`。

### 长期记忆

- 说「**记住：xxx**」「**记住 xxx**」自动存成一条记忆。
- 右键 →「设置…」→「记忆」打开记忆管理（聊天窗口左栏的「记忆」按钮是同一个对话框），可查看 / 添加 / 编辑 / 删除。
- 记忆按 id 顺序拼在 `system` 末尾；只有增改记忆时前缀缓存才会失效一次。

### 定时提醒

- 喝水 / 起身活动 / 护眼 三类，**独立开关**，默认 45 分钟。
- 间隔可选 15 / 30 / 45 / 60 / 90 / 120 分钟或自定义（1–600）。
- 台词随机且不重复上一句。

### 小游戏

- **猜拳**：石头剪刀布，宠物随机出，记录胜负场次。
- **接食物**：食物从上方掉落，鼠标控制宠物左右接，30 秒结束显示得分与历史最高。
- 游戏中暂停散步和提醒；猜拳面板点外面 / Esc / 60 秒无操作会自动关闭。
- 成绩存 `config.json` 的 `games`。

### 节日与生日

- 覆盖：生日 / 元旦 / 春节 / 情人节 / 中秋 / 国庆 / 圣诞。
- **启动 3 秒后**说一次，之后**每个整点**说一次；台词随机不重复。
- 生日格式支持 `1995-03-12` 或只写 `03-12`。
- 春节 / 中秋走农历表 `LUNAR_FESTIVAL_DATES`（已填 2025–2030，按格式加一行即可）。

### 时节特效

纯代码绘制，**不需要图片素材**：

| 特效 | 触发时间 |
|---|---|
| 春节烟花 | 春节前后（公历 2 月 + 农历春节） |
| 国庆烟花 | 10-01 ~ 10-07 |
| 飘雪 | 12-01 ~ 02-15（跨年） |
| 秋季落叶 | 09-15 ~ 11-30 |
| 春日花瓣 | 03-01 ~ 05-31 |
| 中秋月亮 | 农历中秋 |
| 万圣节南瓜灯 | 10-25 ~ 11-02 |

- 启动后按日期自动触发一次，之后每 10 分钟检查（30 分钟冷却），每次持续几秒。
- 菜单可开关（默认开）、手动播放、随时停止。
- 想换成图片素材：把 png 放进 `sprites/`，在 `SEASONAL_ASSETS` 里填一行映射即可，绘制逻辑不用改。

### 余额查询

- 右键「查看余额」，后台请求 `GET https://api.deepseek.com/user/balance`。
- 气泡显示「余额 ¥xx.xx」，并按**已用百分比**（满额按 ¥20 折算）分 6 档播放不同动作与台词：

  | 档位 | 已用 |
  |---|---|
  | 满血 | < 5% |
  | 健康 | < 20% |
  | 注意 | < 45% |
  | 省钱 | < 70% |
  | 告急 | < 92% |
  | 见底 | ≥ 92% |

- 无 Key / Key 无效 / 余额不足 / 超时 / 断网都有明确中文提示。
- **自动查询默认关闭**，开启后间隔最少 30 分钟。

### 其它

- **截屏时隐藏**：开启后宠物用 `WDA_EXCLUDEFROMCAPTURE` 从系统截图里排除，并在 Snipaste / ShareX / 系统截图覆盖层出现时自动隐藏，截完恢复。菜单可关闭（关掉就能被拍到）。
- **减少动效**：读 Windows「显示动画」设置，关闭时跳过挤压与淡入；也可在菜单强制开关。
- **系统监控**：CPU > 90%、内存 > 95%、显卡 > 80°C 时冒泡提醒（10 秒一次）。
- **天气**：右键「查看天气」，`wttr.in` 查询，城市在 `config.json` 的 `city`。
- **单实例**：命名 Mutex，重复启动只提示，不会开第二个。
- **开机自启**、窗口置顶、鼠标穿透、显示/隐藏、回到屏幕内。
- **窗口位置记忆**：宠物坐标存 `pets[]`，聊天窗口几何存 `chat_window`。

## 配置

`config.json`（原子写，损坏时先备份 `config.json.bak` 再回落默认值）：

| 字段 | 说明 |
|---|---|
| `config_version` | 配置版本号（当前 2），用于以后结构迁移 |
| `pets[]` | 每只宠物：`id` / `size` / `x` / `y` / `mode` / `display` |
| `topmost`、`passthrough`、`autostart` | 置顶 / 穿透 / 开机自启 |
| `animation_mode` | `auto` / `on` / `off`（减少动效） |
| `animation_weights` | `idle` / `turn` / `move` 类别权重 |
| `physics` | `gravity` / `elasticity` / `friction` / `power` / `top_bounce` / `pet_collision` / `spring_stiffness` / `spring_damping` |
| `balance` | `auto` / `interval_min` / `last_value` / `last_time` |
| `seasonal_fx` | 只剩 `auto`（总开关在 `features.seasonal_fx`） |
| `features` | 功能开关 `{key: bool}`，控制提醒 / 点击回应 / 节日台词 / 时节特效 / 系统监控 / 截屏隐藏 / 余额自动 / 待机碎碎念 / 甩抛物理 |
| `balance_full` | 余额档位的满额基准（元），默认 20 |
| `ds_api_key` | DeepSeek Key（**明文**，本地文件，注意别外传） |
| `city`、`birthday` | 天气城市 / 生日 |
| `usage`、`games`、`reminders` | 用量累计 / 游戏成绩 / 提醒设置 |
| `chat_window` | 聊天窗口位置尺寸 |

加载时会**逐字段校验**类型与取值范围，出错的字段回落默认值并把字段名写进 `error.log`。

其它数据文件：

| 文件 | 内容 |
|---|---|
| `chats.json` | 多会话聊天历史（`sessions[]` + `current`）。旧格式会自动迁移成「旧对话」会话，迁移前备份 `chats.json.bak` |
| `memory.json` | 长期记忆 |
| `error.log` | 运行日志（1MB 轮转），含未捕获异常与线程异常 |

pip install pyinstaller
pyinstaller --noconfirm 桌宠.spec

产物在 `dist/桌宠.exe`，对方双击即用，无需安装 Python。

## 常见问题

**Q：点「设置 Key」后聊天还是报 Key 无效？**
先确认 Key 来自 `platform.deepseek.com`，且账户有余额；错误提示会区分 401（Key 无效）/ 402（余额不足）/ 429（限流）/ 网络异常。

**Q：截图里看不到宠物？**
默认开了「截屏时隐藏」。右键 →「设置…」→「功能开关」取消「截屏时隐藏」即可被拍到。

**Q：宠物自己乱跑，我想要它固定？**
模式切「原地待着」——只显示正面，也不会自己走动。

**Q：动画太晃眼？**
右键 →「设置…」→「动画」把「减少动效」设成「总是关闭」，会跳过挤压和淡入。

**Q：出了奇怪的 bug？**
看程序目录下的 `error.log`（含时间、级别、完整调用栈）。
